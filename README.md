Поисковый движок для текстовых файлов

Это консольная программа, которая умеет искать слова в текстовых документах. Она читает файлы, строит индекс (запоминает, в каком файле какое слово встречается и сколько раз), а потом по запросу находит самые подходящие документы и сортирует их по релевантности.

Проект сделан в рамках учебного курса, чтобы разобраться с инвертированным индексом, многопоточностью и работой с JSON.

Используемые технологии

C++17 (стандартная библиотека, потоки, файловый ввод-вывод)
CMake версии 3.14 и выше
nlohmann/json (подключается автоматически через CMake)
Google Test (для юнит-тестов, тоже подключается автоматически)

Как собрать и запустить

    Скачайте или склонируйте репозиторий

    git clone https://github.com/gaidyk2011-prog/SearchEngine.git
    cd SearchEngine

    Соберите проект через CMake

    mkdir build && cd build
    cmake ..
    cmake --build .

    После сборки в папке build появится исполняемый файл search_engine.exe (или просто search_engine, если не Windows).

    Подготовьте конфигурационные файлы

    В корневой папке проекта создайте папку config и положите туда два файла:

    config.json — в нём указываются файлы для индексации и максимальное количество ответов.

    Пример:
    {
    "config": {
    "name": "MyEngine",
    "version": "1.0",
    "max_responses": 5
    },
    "files": [
    "resources/doc1.txt",
    "resources/doc2.txt"
    ]
    }

    requests.json — список поисковых запросов.

    Пример:
    {
    "requests": [
    "привет мир",
    "поиск слова"
    ]
    }

    Текстовые файлы, перечисленные в config.json, должны существовать по указанным путям. Если файла нет, программа выдаст предупреждение, но продолжит работу.

    Запустите программу из папки build

    ./search_engine

    После выполнения появится файл answers.json с результатами поиска. Для каждого запроса там будет либо "result": "false", если ничего не найдено, либо список документов с номерами и рангами.

Дополнительные замечания

Если вы работаете в CLion, можно просто открыть папку проекта как существующий проект — CLion сам подхватит CMake.

Чтобы запустить тесты, соберите цель unit_tests и выполните её. Все тесты из папки tests должны пройти успешно.

При первом запуске Windows может показать предупреждение о неизвестном издателе — это нормально для самодельного приложения, нажмите «Выполнить в любом случае». Программа только читает и записывает файлы в той же папке, ничего вредоносного в ней нет.

Если хотите добавить свои текстовые файлы, укажите их пути в config.json. Можно использовать относительные пути от корня проекта или от папки, где лежит исполняемый файл.
