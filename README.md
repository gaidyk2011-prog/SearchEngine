КРАТКОЕ ОПИСАНИЕ ПРОЕКТА: 
SearchEngine - это консольное приложение на C++, реализующее поисковый движок по текстовым файлам. Оно читает список документов из config.json, индексирует их (строит инвертированный словарь), принимает поисковые запросы из requests.json и выдаёт результаты в answers.json. Алгоритмы программы позволяют находить наиболее подходящие документы. Индексация выполняется параллельно в нескольких потоках для ускорения.

ОПИСАНИЕ СТЕКА ИСПОЛЬЗУЕМЫХ ТЕХНОЛОГИЙ:
Сам код полностью писался на языке с++. Из основных библиотек язык использовались: vector, string, fstream, iostream, map, thread, mutex, algorithm. Из дополнительных: nlohmann.

КРАТКАЯ ИНСТРУКЦИЯ КАК ЗАПУСТИТЬ ПРОЕКТ ЛОКАЛЬНО:
Перед запуском программы необходимо настроить параметры программы, а именно: максимальное количество ответов(config.json -> config -> max_responses), пути к текстовым документам на компьютере(config.json -> files), запросы для поиска(requests.json -> requests). 
Далее можете смело запускать саму программу(cmake-build-debug -> search_engine.exe)
После завершения работы программы открываете файл answer.json и получаете ответы на свои запросы. Каждый ответ на каждый вопрос пронумерован и содержит результат поиска(result) true/false, если результат true: документы в которых были найдены слова из вашего запроса(docid) и ревалентность поиска(rank).
